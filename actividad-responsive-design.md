# Actividad: Responsive Design

## Consigna

Adaptá el diseño de la sección de reseñas para que se visualice correctamente en diferentes tamaños de pantalla: computadoras, tablets y celulares.

Utilizá CSS y media queries para modificar la distribución de los elementos según el ancho disponible. En computadoras, mantené la distribución original. En celulares, reorganizá el contenido para facilitar la lectura y evitar que los elementos se superpongan o se salgan de la pantalla.

## Ayudas

- Utilizá `@media (max-width: 600px)` para definir los estilos específicos para celulares.
- Investigá cómo funciona `flex-direction: column` para organizar elementos verticalmente.
- Ajustá los anchos de los contenedores para aprovechar el espacio disponible.
- Modificá los tamaños de fuente, los márgenes y los espacios entre elementos cuando sea necesario.
- Revisá qué sucede con las tarjetas de valoraciones y testimonios cuando la pantalla se hace más pequeña.
- Probá diferentes anchos utilizando las herramientas de desarrollador del navegador.

## Objetivo

Lograr que el diseño sea adaptable, legible y ordenado en distintos dispositivos, sin desbordamientos horizontales y sin perder la estructura visual original.

**Importante:** No es necesario modificar el HTML. Resolvé la actividad trabajando únicamente con CSS.
